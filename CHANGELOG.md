# Changelog

All notable changes to **CarWale** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-28

### Added
- Automotive marketplace platform with multi-parameter vehicle catalog filtering.
- MongoDB / Mongoose schema architectures for users, vehicles, and bookings.
- JWT authentication with bcrypt password hashing and auth guard middleware.
- Multer multipart file upload integration for dealer vehicle imagery.
- Test catalog seed automation script (`seed.js`).
- MIT open source license and technical documentation.

### Fixed
- Sanitized query parameter parsing for price range and fuel type filters.
